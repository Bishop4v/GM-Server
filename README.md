# GM-Server
Website for the Gamemaster Server for the 2026 Escape Room

Steps:
  1st - Install Python on your local hardware
  
  2nd - Install the required Python Packages
    * Open the command prompt (or whatever the local terminal is) then run the following command:
        pip install Flask flask-socketio
        
  3rd - Create a new folder on your computer
    * Inside the folder, create a subfolder named templates
        * Save index.html there
    * Save the Python file (app.py) in the main project folder

Running the Server:
  1st - Navigate to your project folder
    * Copy the path
    
  2nd - Open the terminal then type:
      cd (paste the path you got from the 1st step)
      
  3rd - Now run the Python file:
      python app.py
      
  4th = Paste the site in the search engine
    * When you run the file stuff should be popping up and this will be displayed: http://127.0.0.1:5000
